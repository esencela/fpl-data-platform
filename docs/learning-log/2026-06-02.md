### Issues encountered
- Airflow syntax errors
- Ingestion and dbt containers could not access env variables
- Separated ingestion tasks (fpl_extract, fpl_load etc.) did not share directories as airflow creates separate containers for each task

### Lessons
- Airflow containers need access to Docker network via volume: - /var/run/docker.sock:/var/run/docker.sock
- Airflow DAGs do not allow list >> list for task dependencies. Must be task >> list or list >> task
- Containers created by Airflow through DockerOperator do not inherit environment variables from airflow container, must be passed through environment parameter in DockerOperator
- Create mounted volumes to share data between containers via local host with mount type parameter in DockerOperator 'mounts=[Mount(target='/app/data', source=BASE_DIR, type='bind')]'
- source parameter in Mount() type requires an absolute path variable from host machine, using os.abspath() in an airflow container gives the airflow directory, not host machines
